# Yuvio v1.2.1

Your YouTube Music, on your Discord profile.

Yuvio works with Chrome tabs and the installed YouTube Music app, with a compact dark-mode popup, live preview, and settings that save automatically.

### Included

- Song, artist, album artwork, and playback progress on Discord.
- Custom text, accent colors, link buttons, and pause behavior.
- Privacy controls and artist exclusions.
- A choice of player when both a tab and the installed app are playing.
- A shared Discord application, so you don't need to create your own.

### Fixed in this release

Automatic song transitions now reset the timer correctly. YouTube Music can reuse one media timeline across multiple songs; Yuvio now reads the per-song clock instead.

### Install

Download **YouTube-Music-Presence-1.2.1.zip** below, extract it to a permanent folder, load its `extension` folder through Chrome's **Load unpacked** option, and run **Install companion.cmd**. Open Discord desktop, refresh YouTube Music, and connect from Yuvio's popup.

Requires **Windows x64 + Google Chrome + Discord desktop**. No Discord developer account, token, Node.js, or .NET installation needed. The companion is included. The Windows executable is unsigned.

Use the versioned ZIP for installation, rather than GitHub's automatic Source code downloads. The README has the full setup and update instructions.
